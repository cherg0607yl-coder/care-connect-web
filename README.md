## Environment variables

Copy `.env.example` to `.env.local` and fill in values.

- **`GOOGLE_MAPS_SERVER_API_KEY`** — Used only on the server for Places Autocomplete, Place Details, and Geocoding. Enable the relevant Places/Geocoding APIs in Google Cloud.
- **`NEXT_PUBLIC_GOOGLE_MAPS_API_KEY`** — Used in the browser for the interactive map on search results. Use a **separate** key with the **Maps JavaScript API** enabled and **HTTP referrer** restrictions (localhost + production domains).
- **`NEXT_PUBLIC_SUPABASE_URL`** / **`SUPABASE_SERVICE_ROLE_KEY`** — Supabase project URL and service role key for organization and measurement queries.
